Privacy Policy

Last updated: 20 October 2026

This policy explains what information Shorts Uploader accesses, how it is used and stored, and how access can be revoked. Shorts Uploader is a private, single-user tool operated by Stuart Robinson (United Kingdom). Its only user is its owner, and it is used only with his own Google account and YouTube channel, Blaze Reels Fan Page (@blazereelzfan).

YouTube API Services

Shorts Uploader uses YouTube API Services (the YouTube Data API v3). By using Shorts Uploader you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also handled under the Google Privacy Policy.

Data deletion and revoking access

Access can be revoked at any time from the Google Account permissions page: https://security.google.com/settings/security/permissions. Select “Shorts Uploader” and remove its access. After that, the tool can no longer upload or read anything from the channel.

The refresh token is kept only while the owner continues to use the tool. If access is revoked or the tool is no longer used, the stored token is deleted from the server. Locally stored channel details and upload records can be deleted on request by emailing snapreel247@gmail.com. Videos uploaded to YouTube remain on YouTube under the owner's control and can be managed or deleted in YouTube Studio.

Information accessed

When the owner signs in with Google and grants permission, Shorts Uploader requests these OAuth scopes:

  • youtube.upload – to upload the owner's own videos to his own YouTube channel.
  • youtube.readonly – to read basic details of the owner's channel (such as channel ID and title) and the status of videos uploaded by the tool (such as processing and privacy status).

Through this, the tool handles:

  • An OAuth refresh token (and short-lived access tokens) issued by Google, which let the tool act on the owner's channel within the scopes above.
  • Basic channel information and upload status returned by the YouTube Data API.
  • The videos and their metadata (title, description, tags, privacy setting) that the owner chooses to upload. These are the owner's own content.

Shorts Uploader does not access other people's channels, comments, subscribers, viewing history, contacts, email or any other Google account data.

How information is used

Information is used only to upload the owner's own videos to his own channel and to read his own channel details and upload status so that uploads can be confirmed. It is not used for advertising, profiling, analytics about other people, or any other purpose.

How information is stored

  • The OAuth refresh token is stored on a private server controlled by the owner, in a file with restricted permissions readable only by the owner. It is not stored in source code or shared files.
  • Access tokens are short-lived and are held only in memory while a request is being made.
  • Channel details and upload status may be kept in simple server logs or records for the owner's own reference, on the same private server.
  • Shorts Uploader does not use cookies or tracking on these web pages.

Sharing

Information is not sold, rented or shared with anyone. The only party it is sent to is Google/YouTube, through the YouTube Data API, in order to perform the uploads and status checks described above.

Children

Shorts Uploader is not directed at children and is used only by its adult owner.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new “Last updated” date.
