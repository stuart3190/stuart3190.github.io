Shorts Uploader

Last updated: 20 October 2026

Privacy Policy Terms of Service

Shorts Uploader is a small, private tool that uploads finished YouTube Shorts made by Stuart Robinson to his own YouTube channel, Blaze Reels Fan Page (@blazereelzfan). It runs on a private server and is used only by its owner. It is not offered to the public and does not have other users.

Uses YouTube API Services

This tool uses YouTube API Services (the YouTube Data API v3) to upload videos. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy and our Privacy Policy.

What it does

  • Uploads Stuart Robinson's own finished short videos, with their title, description and related details, to his own YouTube channel.
  • Reads basic information about that same channel and the status of its uploads (for example, whether a video has finished processing), so the tool can confirm an upload worked.

How it works

Shorts Uploader uses the official YouTube Data API v3, authorised through Google OAuth. It requests only these permissions:

  • https://www.googleapis.com/auth/youtube.upload – to upload videos to the owner's channel.
  • https://www.googleapis.com/auth/youtube.readonly – to read the owner's channel details and upload status.

It does not download, copy or re-upload anyone else's content, and it does not interact with other YouTube users.

YouTube and Google terms

Shorts Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

Your data and revoking access

The OAuth refresh token is kept as an encrypted secret on a private server. Nothing is shared or sold. Access can be revoked at any time at https://security.google.com/settings/security/permissions. Full details are in the Privacy Policy.
